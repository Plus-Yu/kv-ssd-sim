# C2 · K3 真实尺寸下的两轮 agent SSD 负载

2026-11-19。对同一份真实 WEKA 两轮切片完成三次通过严格验收的独立空盘回放。从首轮 HTTP 发送到设备观测结束，FEMU 每次收到 **2,292.29–2,292.32 MiB 写**、**4.0–8.0 KiB 读**。三次末轮响应后均有设备写入，共 104–122 笔/次。每次最后一笔数据 I/O 都晚于响应结束，间隔 72.28–74.09 秒。这个观测窗口包含轮间空闲、后台落盘和收尾。

## 样本与冻结条件

使用 trace_0504 前两轮，输入/输出为 11,133/139、11,300/96 tokens；AIPerf 0.13.0 按因果依赖回放，保留 4 秒 think time。按原始线上 token 重算，前两轮完整共享 173 个 64-token WEKA 块；K3 管理块 1,536 tokens，Store chunk 128 tokens。以实际 CPU 缓冲和原生 vLLM 调度、Mooncake worker 传输运行，FEMU、应用和 AIPerf 均在客体内。计算预算 prefill/decode 10/2 ms，TCG 调度、内容准备、内存拷贝及传输另占墙钟时间。

沿用 C1 的 93 层原生规格、八个逻辑 rank、一个共享 embedded Store、22 个管理块/rank、2,520 MiB Store 段、2,840 MiB offload 配额。设备使用 3 GiB namespace、4 GiB 原始几何，客体内存 8 GiB，TCG 双 vCPU。主表的三次运行目录后缀为 01、02、05。03 的服务进程在就绪前退出，发送请求数为零，客体退出码为 1。日志未给出进程终止根因，原样保留在 [启动失败记录](../evidence/ssd-c2/failed-startup-03.tar.gz)。04 完成了两个请求，但第二次发送前 diskstats 在途为 7、trace issue/complete 深度为 0，采样区间内没有块事件。保留这次样本，05 沿用原严格标准独立补测。三次有效运行均重新启动并格式化各自的 RAM 后端，轮间自然保留本地 KV、Store 和文件页缓存。验收逐项比对输入、程序与配置哈希、固件、设备参数、请求摘要。[C1 准入与容量结果](阶段C1-K3真实尺寸与容量验收.md) · [固定来源及选择记录](../datasets/k3-c2/selection.json)

## 默认系统的突发与地址重写

按原始块事件复核同一观察窗口（首轮 HTTP 发送至设备观测结束）。将所有写 issue 的 512 B 扇区区间取并集，可测出这次回放覆盖了多少不同地址。“重复写字节占比”取（累计提交写字节 − 并集字节）/ 累计提交写字节。同一地址写三次时，后两次均计入重复写。另从首发送时刻起按秒分桶，选写入量最大的十个完整秒桶，分母仍取全窗口写入字节，十个桶可以不相邻。[块事件归档与逐秒原表](../evidence/ssd-c2/)

| 运行 | 流量最高的十个秒桶占全部写字节 | 唯一写地址覆盖（B） | 重复写字节占比 |
|---|---:|---:|---:|
| 01 | 89.74% | 2,403,545,088 | 0.00545% |
| 02 | 91.33% | 2,403,516,416 | 0.00579% |
| 05 | 78.09% | 2,403,565,568 | 0.00307% |

在这份空盘、两轮样本里，大部分写入集中在少数秒内，且几乎每个写入字节都落到本窗口首次写到的地址。该指标描述主机 LBA 的重写，长期运行中的地址复用和 NAND 内部搬迁需要单独观测。

## 复现与范围

本报告刻画这一串行、两轮、小容量配置的单盘主机侧负载。未覆盖其余会话、并发子 agent、八个独立 Store 客户端或 B300 实物的生产时序。对照布局和采集 NAND 计数分别是 D、E 阶段。

在项目根目录执行以下命令可重新核验归档。图表和逐秒数据都可由原始事件独立生成。

```bash
(cd evidence/ssd-c2 && sha256sum -c SHA256SUMS)
d=$(mktemp -d)
tar -xzf evidence/ssd-c1/femu-c1-online01.tar.gz -C "$d"
for a in evidence/ssd-c2/femu-c2-*.tar.gz; do tar -xzf "$a" -C "$d"; done
.venv-aiperf/bin/python scripts/analyze_k3_ssd.py "$d/femu-c1-online01" \
  --repeats "$d"/femu-c2-natural-0[125] --output "$d/result"
cmp "$d/result/summary.json" evidence/ssd-c2/summary.json
```

在本机重新运行三次实验可执行 `.venv/bin/python scripts/run_k3_ssd.py c2 --calibration outputs/femu-c1-online01 --prefix femu-c2-repeat`，使用尚未占用的前缀。[逐次统计](../evidence/ssd-c2/summary.json) · [逐秒原表](../evidence/ssd-c2/timeline.csv) · [全部原始证据](../evidence/ssd-c2/)
