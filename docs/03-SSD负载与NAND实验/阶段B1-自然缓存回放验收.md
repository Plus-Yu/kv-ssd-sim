# 阶段 B1 · 真实 WEKA 两轮自然缓存回放

2026-11-19，使用 `trace_0001` 的前两轮，AIPerf 0.13.0 通过 HTTP 驱动 vLLM、Mooncake 和 FEMU BlackBox。**第二轮的 71,168 个共享前缀 token 全部在 vLLM 本地复用，Mooncake GET 为零。** 结束时 2,272 个已发布对象均同时具有 MEMORY 和 LOCAL_DISK 副本。该结果来自一次 TP1 tiny、单盘、固定计算预算的自然回放。[验收数据](../../evidence/ssd-b1/summary.json) · [原始归档](../../evidence/ssd-b1/trial.tar.gz)

## 与受控冷读相同的工作负载

与阶段六 fast01 对照，实际 wire prompt 的两个 SHA256、源 trace、混合配置、FEMU 版本和盘几何均一致。两次均使用 2 vCPU、4 GiB 客体、384 MiB namespace、40 µs NAND 页读、4,096 个缓存块、81,920 上下文、每 prefill/decode step 10/2 ms。自然模式由 `--natural-cache` 写入客体输入回执；启动命令、原生服务端配置和事件记录共同核对实际策略。第二轮在前轮结束后 12.051 s 获得回放许可，源 think time 为 12 s。[冷读基线](../02-K3参考部署与验证/KimiK3-B300步骤6验收报告.md)

| 轮次 | 输入 / 输出 tokens | vLLM 本地复用 | Store 加载 | 实际计算的 prompt tokens |
|---|---:|---:|---:|---:|
| 第一轮 | 71,175 / 169 | 0 | 0 | 71,175 |
| 第二轮 | 72,762 / 296 | 71,168 | 0 | 1,594 |

本地复用量按本原型无推测解码的调度账本核算。每轮调度 token 总数减去输出长度减一得到实际 prefill 数，以输入长度扣除实际 prefill 和外部加载得到本地复用量。共享前缀另用收到的 prompt 块哈希核实。冷读 fast01 的第二轮同样只计算 1,594 个 prompt tokens，但另外 71,168 个来自磁盘恢复。自然模式在请求结束后读取副本状态快照，允许只有内存副本或已经淘汰的键；本次没有强制驱逐、前缀重置或清理客体页缓存。

## SSD 实际收到的流量

按目标 NVMe 的块提交时刻统计。每轮从 AIPerf 原始 HTTP 开始时刻计至服务端最后一条响应完成事件，两轮间隙单列。会话窗口保留空闲期并包含轮间的后台写入。

| 窗口 | 读笔数 / 字节 | 写笔数 / 字节 |
|---|---:|---:|
| 第一轮 HTTP 请求 | 0 / 0 | 36 / 7,110,656 |
| 两轮之间 | 0 / 0 | 24 / 6,139,904 |
| 第二轮 HTTP 请求 | 0 / 0 | 11 / 380,928 |
| 会话合计 | 0 / 0 | 71 / 13,631,488 |
| 整个 ftrace 记录 | 3 / 20,480 | 110 / 14,503,936 |

从首轮发送到第二轮响应结束，FEMU 共收到 71 笔写、13.00 MiB，读为零。其中轮间有 24 笔写、约 5.86 MiB，占会话写入量的约 45%。整个采集记录还覆盖服务启动和响应之后的 I/O，包含 3 次读、20 KiB。块层字节包含可能的文件系统元数据；对象归因和后台排空时间另行测量。226 条 ftrace 提交与完成记录全部配平，未检测到缓冲覆盖、错误完成或同键配对歧义。

## 复现

在项目根目录使用新的 trial 名运行同一自然基线。

```bash
.venv/bin/python scripts/run_femu.py --trial femu-b1-repeat01 \
  --workload aiperf --natural-cache --input datasets/kimi-k3-b300-step1/slice.json \
  --num-blocks 4096 --max-model-len 81920 --nand-read-ns 40000
.venv/bin/python scripts/verify_femu.py outputs/femu-b1-repeat01
```

离线复核会重建逐轮调度账本、GET 批次、副本快照与块事件统计。在新目录解包以保留原始证据。

```bash
(cd evidence/ssd-b1 && sha256sum -c SHA256SUMS)
mkdir -p outputs/b1-offline
tar -xzf evidence/ssd-b1/trial.tar.gz -C outputs/b1-offline
.venv/bin/python scripts/verify_femu.py outputs/b1-offline/femu-b1-natural01
cmp outputs/b1-offline/femu-b1-natural01/verification.json evidence/ssd-b1/summary.json
```

当前使用短回放的 ftrace 缓冲。B2 将单独验证持续采集、全窗口 diskstats 对账和后台排空时刻。本次发生零次实际 GET；多次 GET 解析、分层副本、内容校验失败及冷读模式必须出现设备读的语义另以回归用例核对。阶段六 fast01 的原始归档已用更新后的验收器复核通过。
